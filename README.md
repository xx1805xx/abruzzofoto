# Abruzzo Foto — restyling

Sito fotografico statico in italiano. Repository dedicato ad Abruzzo Foto, separato da Formaclub.

## Pubblicazione
GitHub Pages: branch `main`, cartella `/docs`.

## Funzionalità
Galleria di 26 fotografie con filtri, ingrandimento e navigazione da tastiera. Layout responsive, menu mobile e richiesta informazioni attraverso l’app email dell’utente. Nessun server necessario.

Le fotografie provengono da abruzzofoto.it; i diritti restano ai rispettivi titolari.
