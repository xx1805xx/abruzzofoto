# Abruzzo Foto — Dentro l'istante

Portfolio fotografico statico, in italiano. Sito: https://xx1805xx.github.io/abruzzofoto/

## Pubblicazione
GitHub Pages: branch `main`, cartella `/docs`. Nessuna installazione o compilazione richiesta.

## Esperienza
Copertina a pieno schermo con cambio fotografia, controlli e presentazione opzionale. Indice delle raccolte con anteprima interattiva, vista galleria con filtri, album dedicati e visualizzatore con tastiera e swipe. Richieste informazioni tramite email predisposta nell'app dell'utente. Menu mobile, animazioni di ingresso e rispetto delle preferenze di movimento ridotto.

Le 26 fotografie provengono dal sito originale abruzzofoto.it; i diritti restano ai rispettivi titolari. Nessun modulo invia dati a un server. I caratteri sono caricati da Google Fonts con alternative di sistema.

## Direzione visiva
Implementazione originale per GitHub Pages, con riferimenti di composizione ai portfolio fotografici Jett e Stillness. Non include codice né componenti commerciali di quei template.

Progetto autonomo, separato da Formaclub.
